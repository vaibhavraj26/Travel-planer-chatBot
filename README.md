# 🧭 Travel Planner ChatBot

A simple and interactive **chat-based travel planning assistant** that helps users plan their trips using natural language.

🟢 Live Demo: [Travel Planner ChatBot](https://vaibhav5860.github.io/Travel-planer-chatBot/)

---

## ✨ Features

- 💬 Chatbot interface for travel planning
- 🌍 Provides travel suggestions and assistance
- ⚡ Powered by [Gemini AI API](https://ai.google.dev/)
- 🎨 Built using HTML, CSS, and JavaScript
- 📱 Responsive and lightweight

---

## 📂 Project Structure

```bash
├── index.html   # Main interface of the chatbot
├── README.md    # This file
```
⚠️ Note: Gemini API key and related calls have been removed from index.html (line 101) to keep the code secure and safe from abuse.

🔧 Technologies Used
HTML – Structure of the page
CSS – Styling and layout
JavaScript – Chat logic and Gemini API integration
Gemini API – For AI-powered responses (removed for public repo)

🛠️ How to Use
Clone the repository:

bash
git clone https://github.com/vaibhav5860/Travel-planer-chatBot.git

Open index.html in your browser.
Add your Gemini API key where needed (line 101 of index.html).

🔐 Security Note
The actual Gemini API key has been intentionally removed to prevent misuse.
If you're running this locally or deploying yourself, be sure to secure your API key properly.
